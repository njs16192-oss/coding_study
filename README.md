# 코테 노트

프로그래머스 Java 풀이 정리 파일(`content/코테_누적정리.txt`)을 웹과 모바일에서 보기 좋게 보여 주는 앱입니다.
문제별·유형별 필터, 검색, 힌트 본 문제와 복습일 표시, 코드 하이라이팅, 복습용 객관식 퀴즈가 있습니다.

## 내용 업데이트

`content/코테_누적정리.txt` 를 새 파일로 바꿔서 `main` 에 올리면 1~2분 뒤 사이트가 자동으로 갱신됩니다.
GitHub 웹에서 `content` 폴더 → **Add file → Upload files** 로 같은 이름의 파일을 올려도 됩니다.
휴대폰에 설치한 앱은 다음에 열 때 "업데이트됐어요" 알림이 뜹니다.

## 파일 규칙

지금 쓰는 형식을 그대로 읽습니다.

| 파일의 모양 | 화면에서 |
| --- | --- |
| `// ====` 사이의 `// N. 제목` | 섹션 (치트시트, 실수/팁, 틀렸던 포인트, 문제, 우선순위) |
| `// ---------- 문제명 -> 핵심 ----------` | 문제 카드 하나 |
| 헤더 다음 `//` 주석 줄 | 핵심 개념 (`// 내 풀이 :` 로 시작하면 따로 강조) |
| 주석이 아닌 줄부터 | 코드 (하이라이팅 + 복사) |
| 틀렸던 포인트 `- ... (의상)` | 괄호 안 문제 이름으로 그 문제 카드에 연결 |
| 치트시트 `코드   // 설명` | 메소드 표 한 줄 + 퀴즈 |

### 선택 메타데이터 (문제 헤더 바로 아래)

```java
// ---------- 게임 맵 최단거리 -> BFS (격자 최단거리) ----------
// @tags: BFS, 그래프          (없으면 키워드로 자동 추론, 화면에 "자동" 표시)
// @hint: yes                  (힌트/풀이를 봤으면 yes)
// @review: 2026-11-08         (복습일, 여러 개면 쉼표)
// @solved: 2026-10-28         (푼 날짜)
// @level: 2
// @quiz: BFS 에 쓰는 자료구조는? | Queue | Stack | PriorityQueue   (질문 | 정답 | 오답...)
```

복습 완료 체크와 퀴즈 기록은 각 기기(브라우저)에 저장됩니다.

## 올리기 전에 확인

```bash
npm install
npm run check        # 파일을 어떻게 읽었는지 요약 + 형식 경고
npm run dev          # 로컬에서 보기
```

## 기술

React + TypeScript (Vite), Tailwind CSS, Shiki (빌드 때 Java 하이라이팅), Fuse.js (검색), vite-plugin-pwa (홈 화면 설치·오프라인), GitHub Pages + Actions.
